HealthMCP Privacy Policy

Last updated: 4 November 2026

HealthMCP is a personal, self-hosted app operated by Assawin Boontep ("I", "me"). It reads activity and exercise data from Huawei Health so that I can view my own data from my Huawei Watch. This policy explains what data HealthMCP uses and how it is handled.

1. Who can use HealthMCP

HealthMCP is for my personal use only. It is not offered to the public, and no other users are signed up.

2. Data HealthMCP reads

With your permission given on Huawei's authorization page, HealthMCP reads (and never writes) the following data through the HUAWEI Health Kit RESTful API:

  • Activity: steps, distance, ascent and altitude, calories, daily activity summary
  • Exercise records: workout type, duration, distance and workout heart rate
  • Up to one month of the above data recorded before authorization

HealthMCP also receives an access token and refresh token from Huawei so it can keep reading the data you allowed.

3. How the data is used

The data is used only to show daily, weekly and monthly summaries and trends to the person who authorized it, including through an AI assistant that I connect to my own server. It is not used for advertising, profiling, or medical diagnosis.

4. Where the data is stored

Data and tokens are stored in a database on my own computer/server. They are not uploaded to any other storage service. Data shown through an AI assistant is sent to that assistant only when I ask it a question about my data.

5. Sharing

HealthMCP does not sell, rent or share health data with third parties.

6. Retention and deletion

Cached data is kept only as long as needed to show summaries. You can revoke HealthMCP's access at any time in your HUAWEI ID account settings or in the Huawei Health app. After access is revoked, HealthMCP can no longer read new data, and stored data and tokens can be deleted on request.

7. Security

Access to the server is limited to me. Connections to Huawei use HTTPS, and the app secret and tokens are kept out of public code.

8. Changes

If this policy changes, the date above will be updated.

9. Contact

Questions or deletion requests: open an issue on GitHub
